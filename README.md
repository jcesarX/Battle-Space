Battle Space

Jogo de naves 2D desenvolvido em Python utilizando Pygame.

O projeto foi desenvolvido como forma de praticar programação, organização de código, lógica de jogos, gerenciamento de estados e programação orientada a objetos.

Sobre o jogo

O jogador controla uma nave e enfrenta diferentes tipos de inimigos durante a progressão do jogo.

O projeto possui diferentes sistemas responsáveis por combate, movimentação, colisões, pontuação, vida, inimigos, boss, animações e efeitos sonoros.

Funcionalidades

- Controle da nave do jogador
- Sistema de disparos
- Diferentes tipos de inimigos
- Boss
- Sistema de vida
- Sistema de pontuação
- Detecção de colisões
- Animações de explosão
- Efeitos sonoros e música
- Sistema de pausa
- Progressão do jogo
- Tela de vitória e derrota
- Efeito de paralaxe

Tecnologias

- Python
- Pygame

Conceitos praticados

- Programação orientada a objetos
- Organização modular
- Gerenciamento de estados
- Detecção de colisões
- Manipulação de eventos
- Animação
- Gerenciamento de recursos
- Estruturação de projetos Python

Execução

Clone o repositório:

git clone https://github.com/jcesarX/Battle-Space.git
cd Battle-Space

Instale as dependências necessárias e execute o arquivo principal do projeto.

Objetivo

Projeto desenvolvido para fins acadêmicos e de aprendizado, com foco no desenvolvimento de jogos utilizando Python e Pygame.
